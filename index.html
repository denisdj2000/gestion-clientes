Configura Firebase primero

Esta app todavía tiene valores de ejemplo en la configuración de Firebase. Antes de usarla:

  1. Abre index.html y busca el bloque window.__FIREBASE_CONFIG__.
  2. Reemplaza cada valor "TU_..." por los datos reales de tu proyecto de Firebase (Configuración del proyecto → Tus apps → Config del SDK).
  3. Guarda el archivo y vuelve a cargar esta página.

Sigue la guía completa en README.md para crear el proyecto, activar Authentication y Firestore, y publicar la app.
